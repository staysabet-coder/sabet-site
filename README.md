# ثابت — موقع الحملة التوعوية

موقع عربي باتجاه RTL لحملة «ثابت». يحتوي على صفحة رئيسية، وصفحة «عن الحملة»، وتجربة تفاعلية من 15 بطاقة، مع نتيجة نهائية وإمكانية إعادة اللعب وروابط الشبكات الاجتماعية.

## التشغيل محليًا

```bash
npm run dev
```

## بناء نسخة ثابتة

```bash
npm run build
```

يستمع الخادم إلى المنفذ `3000` افتراضيًا ويحترم متغير `PORT`. لا يحتاج الموقع إلى قاعدة بيانات أو تسجيل دخول؛ بيانات البطاقات محلية في `src/cards.js`.

## النشر على Vercel

1. ارفع المجلد على GitHub (أو استخدم `vercel` من سطر الأوامر).
2. في Vercel اختر Framework Preset: **Other** — الإعدادات في `vercel.json` (البناء: `npm run build`، المخرجات: `dist`).
3. مسارات `/about` و`/cards` تعمل عبر rewrite إلى `index.html`.

## وسوم المشاركة (Open Graph)

- صورة المشاركة: `assets/og-image.png` (1200×630).
- رابط الموقع المطلق يُحقن وقت البناء تلقائيًا من متغيرات Vercel.
- عند ربط دومين مخصص: أضف متغير بيئة `SITE_URL` (مثال: `https://sabet.example.com`) في إعدادات المشروع على Vercel ثم أعد النشر.
- بعد النشر، جرّب الرابط في أداة تصحيح فيسبوك (Sharing Debugger) لتحديث المعاينة المخزّنة.

## البنية

- `index.html`: الهيكل والبيانات الوصفية.
- `styles.css`: الهوية البصرية والتخطيطات المتجاوبة.
- `src/app.js`: التنقل والعرض وتدفق البطاقات والنتيجة.
- `src/cards.js`: أسئلة البطاقات والإجابات والمعلومات التوعوية.
- `assets/`: صور الهوية وصورة المشاركة.
- `server.js`: خادم HTTP صغير مع fallback لمسارات الصفحات.
- `scripts/build.js`: بناء النسخة الثابتة في `dist/`.
- `vercel.json`: إعدادات النشر (rewrites، كاش الصور، headers).
